# Tasks

This is a central starting point for manual certificate operations in SCEPman Certificate Master. From here, you can browse issued certificates via Jamf and Intune, as well as revoked certificates, and download or revoke individual ones. You can also jump directly to a certificate request type: Generic CSR, (Web) Server, TLS Inspection, Code Signing, Device, or User.
