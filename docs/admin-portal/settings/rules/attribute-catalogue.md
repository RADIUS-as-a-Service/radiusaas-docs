# Attribute Catalogue

<figure><img src="../../../.gitbook/assets/image (570).png" alt=""><figcaption></figcaption></figure>

The Attribute catalogue is a picker list of the RADIUS attributes your rules are allowed to return: standard VLAN/tunnel attributes (DHCP-IEEE-802.1Q-VLAN-ID, SN-Assigned-VLAN-ID, Egress-VLANID and vendor-specific equivalents) plus other RADIUS attributes such as Filter-Id, Class, Framed-MTU, Tunnel-Password, or vendor-specific ones like Cisco-AVPair and Fortinet-Group-Name. Adding an attribute here only makes it selectable in a rule's assignments; it does not apply it anywhere by itself. Attributes not already listed can be added by searching the RADIUS dictionary.
